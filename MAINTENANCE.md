# Maintenance expectations

Atria CLI is published as a source-first engineering asset. Maintenance is
best-effort; there is no guaranteed response time, support contract, hosted
runtime, or prebuilt Windows binary promise.

The stable maintenance boundary is:

- keep source manifests, dependency inventory, SBOM, tests, and documentation
  aligned with each release;
- accept focused fixes that preserve explicit user control and local-first
  operation;
- publish breaking protocol or permission changes visibly;
- handle security reports privately before public disclosure.

Commercial support, enterprise integration, signed binaries, and managed
distribution may be offered separately. Their availability is not implied by
the open-source repository.
